## Hard rules learned this session

- **`_nogit/` is create-only.** Never overwrite or modify a file there; write results under new
  names. There is a memory file for this. The action-rules hook enforces it.
- **Use literal paths** in shell commands. A path built from a variable such as `$M` makes the
  hook refuse or ask.
- **Answer the user's question before making changes.** The user objected when edits came
  before an answer.
- **`AskUserQuestion` "clarify" choice:** reply with only the question text, then stop.
- **Don't stop between phases** unless a verification fails or a design decision proves
  wrong; then stop and ask, and update `design.md` with the answer.
- **Commits end with** `Claude-Session: https://claude.ai/code/session_01Xeq4mD1zWMtU2cbYYc1VyE`.
  Commit only when asked or as part of the agreed phase plan.

## Workbook facts the next session is likely to need

Full detail is in `design.md` sections 4–6.

**Expenditures:**
- Data rows 7–250; header row 6; row 3 has the vendor totals, row 4 the totals, row 5 the
  provenance notes.
- Columns:
  - A–F: row #, item, element, GL account, GL account name, Spatac flag.
  - G–I: keys and the RFS check.
  - J–N: current year (Approved, Actual, Mid-year, Latest, Current).
  - O–Q: next year (Mid-year, Late-year, Current).
  - R–T: year after (Mid-year, Late-year, Current).
  - U: Reason; V: Working notes.
  - W–AX: RFS block (28 years); AY–BZ: Revised block.

**Medium_Term_Cashflow:**
- Years B3:G3.
- Row 10: held maturities; row 11: planned maturities, computed from earlier grid columns
  only, to avoid a circular reference.
- Rows 13–17: planned investment grid (17 is the 5-year balancing figure).
- Row 21: closing; row 22: blank; row 23: carry-over; row 24: adjustment to minimum; row 25:
  minimum.
- Rows 28–30: RFS vs Revised; rows 32–34: balance comparison (dropped from the plan).

**Schedule_of_Investments:**
- Held rows 7–46; Planned header row 48; Planned rows 49–78; totals row 80.
- Year columns N–X; helper columns K–M folded.

**Projected_Balances:**
- Inputs B4:B8; lows table G4:I10.
- Year rows 13–62; inputs in F/G; check columns X–AA folded.

**Settings:** B4 base year, B5 minimum target, B6 the target's year, B7 new-investment rate.
