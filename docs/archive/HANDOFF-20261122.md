## Hard rules learned (both sessions)

- **`_nogit/` is create-only.** Never overwrite or modify a file there; write results under new
  names. The user deletes files there, not Claude.
- **File names:** `Name-YYYYMMDD.xlsx` with the current **Eastern** date. If that name exists,
  use the next letter: `Name-YYYYMMDDa.xlsx`, then `b`, `c`… This is the user's standard for
  binary files and for any file not under git. Don't ask.
- **Dates:** run `TZ=America/New_York date +%F`. The session's date notice and the container
  clock are UTC and roll over at 7 pm Eastern.
- **Name the workbook before extracting the plan:** the plan's cover records its source's name.
- **Answer the question first**, before making changes, and **answer concisely**: a few short
  points, no long sectioned replies.
- **Don't invent filler options** or ask what has an obvious answer.
- **Readable formulas** (design 3.3): `LET` to name parts, `IFS`/`SWITCH` instead of nested
  `IF`s, several lines for long formulas, helper columns where they help.
- **Protection:** what matters is each cell's own Protected flag, not whether the sheet is
  protected. The workbook is delivered with every Spatac tab protected (no password).
- **Use literal paths** in shell commands; a path built from a variable makes the hook refuse
  or ask.
- **`AskUserQuestion` "clarify" choice:** reply with only the question text, then stop.
- **Commits end with** `Claude-Session: https://claude.ai/code/session_01Xeq4mBf3eFvyM7Mf2EpFF8`.
  Commit only when asked or as part of an agreed plan. Push only on explicit instruction.

## Workbook facts the next session is likely to need

Full detail is in `design.md` sections 4–6 and 13.

**Expenditures:**
- Rows: 3 vendor totals (label in V3), 4 totals, 5 variance vs RFS, 6 provenance and the block
  years, 7 headers; items 8–249; ▼ End row 250. Names run from row 7 to row 250.
- Columns:
  - A–F: Row #, Item, element, GL account, GL account name, Spatac row (S); protected.
  - G–I: keys and the RFS check (`LET`/`IFS`: "Not in RFS", "No RFS amounts", "In RFS: clear S").
  - J–N: current year (Approved, fixed; Actuals; Mid-year; Late-year; Current).
  - O–Q, R–T: next year and the year after (Mid-year, Late-year, Current).
  - U: reason for change; V: working notes; W–AX: RFS block; AY–BZ: Revised block (`SWITCH`).
- L–T show a typed 0 as `0`. N, Q and T are empty when their inputs are.
- Title in A1. A and B are left-aligned. No item sort key: sort by Row # to restore order.
- The AutoFilter works while the tab is protected.

**Medium_Term_Cashflow:**
- Typed years in B3:G3; ▶ End column H; check cell A2.
- Rows: 5 opening cash, 6 payables, 8 contributions, 9 revised expenditures, 10 held
  maturities, 11 planned maturities (`LET`, from earlier grid columns only: anything else is
  circular), 13 planned new investments total, 14–18 grid (18 is the 5-year balancing figure),
  20 closing, 22 carry-over, 23 adjustment to minimum, 24 minimum, 28–30 RFS vs Revised, 32–34
  balance comparison (not in the plan).
- Rollover: delete column B, insert a column before ▶ End. `#REF!` shows until B5 is typed.

**Schedule_of_Investments:**
- Held label row 6, held rows 7–46, ▼ End row 47; Planned header 48; Planned rows 49–78;
  totals row 80. Year columns N–X; K–M folded.
- Each Planned row belongs to one grid cell, by its typed Grid # in column M (1–5: the terms in
  the first year column). The row is blank when its cell is empty.

**Projected_Balances:**
- Inputs B4:B12 (dropdowns B4, B6, B7). D4 is the start year (`PB_StartYear`); D5 the starting
  balance (`PB_StartBalance`). Lowest margins G4:I10.
- Header row 14; years 2024–2073 in rows 15–64. RFS baseline B–H. What-if J–U: Opening
  balance, Expenditures, Contribution increase, Contributions, Interest rate, Interest, Closing
  balance, **Q: difference from RFS balance**, margins R–T, U per unit per month. W: inflator
  (folded).
- Rows before the start year are blank. With B4, B6 and B7 set to RFS, Q is 0 in every year.

**Settings** (last tab): B4 base year, B5 minimum target, B6 its year, B7 new-investment rate;
the A9 note on inflation.

**Excel versions:** `IFS` and `SWITCH` need Excel 2019 or later; `LET` needs Excel 2021 or later.

**Known open questions in the data:** the 17 doubt comments in Expenditures column U, chiefly
3.9, 6.3, 18.3.1, 18.11, 15.5a and 11.2, plus the dropped RFS amounts of 5.1, 5.5, 5.6 and 18.4.
