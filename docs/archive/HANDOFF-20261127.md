## Hard rules learned (all sessions)

Everything in the earlier handoffs still holds. New:

- **Check your own work before handing it over** (memory `self-review-formatting`). Run
  `layout_lint.py` on every build, the Investment Plan included, render the tabs with
  `render.py` and read the pages. The user called the recurring display defects carelessness.
- **No fixed row heights on input rows.** Notes are edited over time, and LibreOffice cannot
  resize rows on a protected tab; automatic rows re-fit on every edit.
- **The vendor tabs are a data source:** wrap their description columns, no fixed heights, and
  if text still does not show fully, so be it.
- **Name the tab on every cell reference addressed to the user** (memory `qualify-cell-refs`);
  the user rejected a question that listed cells without their tab.
- **Propose before changing a formula or value the user did not ask for** (memory
  `announce-unrequested-changes`), and when the user gives an instruction, say whether it is
  sound before carrying it out.
- **Excel reads every formula as legacy.** Do array arithmetic only inside functions that
  evaluate arrays themselves (`SUMPRODUCT`, `SUMIF`, `MINIFS`); never wrap it in `IF` or
  `IFERROR` there, and never hold a computed array in a LET name (Excel adds `@`). A LET name
  holding a range or a single value is fine.
- **AutoFilter buttons** take about 0.5 cm from each heading in Expenditures row 7; the PDF
  renders do not show them. `FILTER_BUTTON` in `layout_lint.py` allows for them.
