## Hard rules learned (all sessions)

- **Commit trailer:** use the `Claude-Session:` line when the system supplies one; omit it
  when none is supplied.

  (memory `no-reasking`).
- **No formula turns an error into a value** (design 16.5). The kept exceptions are listed
  there, each with its reason.

  is history; new work edits the latest baseline with a dated script, as
  `update_20261126.py` does.
- **Inserting rows on one tab can shift another tab's validation references** in LibreOffice.
  Set validations again after any row insertion, and check the saved file.
